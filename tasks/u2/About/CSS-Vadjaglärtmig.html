CSS - Vad jag har lärt mig.

  • Display = Bestämmer hur ett element visas.
  • Color = Ändrar färg.
  • Background-color = Ändrar färgen på bakgrunden av texten.
  • Font-size = Ändrar storleken på texten.
  • Font-weight = Bestämmer tjockleken på texten.
  • Padding = Gör utrymme innuti ett elements kant.
  • Margin = Gör utrymme innuti ett element.
  • Gap = bestämmer avstånd mellan element.
